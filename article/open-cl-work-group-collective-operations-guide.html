OpenCL Work-Group Collective Operations Guide

OpenCL provides a dedicated suite of built-in collective functions designed to coordinate computation and data exchange across all work-items within a single work-group. Introduced primarily in the OpenCL 2.0 C specification, these functions eliminate the need to write manual parallel reduction or scan algorithms using local memory and explicit barriers. This article outlines the specific functions that constitute the OpenCL work-group collective operations library, categorizing them by their algorithmic roles: broadcast, reduction, scan, synchronization, and asynchronous memory transfers.

Broadcast Operations

The broadcast function allows a value computed by or assigned to a single work-item to be distributed across every work-item in the work-group.

  • work_group_broadcast(T x, size_t local_id)
  • work_group_broadcast(T x, size_t local_id_x, size_t local_id_y)
  • work_group_broadcast(T x, size_t local_id_x, size_t local_id_y, size_t local_id_z)

The broadcast operation takes a scalar or vector type T from the work-item identified by the specified local ID coordinate(s) and returns that value to all work-items in the work-group.

Reduction Functions

Work-group reduction functions combine input values from all work-items into a single scalar result, which is then made available to every work-item in the work-group.

Arithmetic Reductions

  • work_group_reduce_add(T x): Computes the sum of x across all work-items.
  • work_group_reduce_min(T x): Finds the minimum value of x across all work-items.
  • work_group_reduce_max(T x): Finds the maximum value of x across all work-items.

These operations support signed and unsigned integer types as well as floating-point types (including half, float, and double where supported).

Logical Reductions

  • work_group_all(int predicate): Returns a non-zero value to all work-items if predicate evaluates to non-zero for all work-items in the work-group; otherwise, returns 0.
  • work_group_any(int predicate): Returns a non-zero value to all work-items if predicate evaluates to non-zero for at least one work-item in the work-group; otherwise, returns 0.

Scan (Prefix Sum) Functions

Scan operations compute generalized prefix sums across the work-group, ordered by the 1D linear local ID (local_id_z * local_size_y * local_size_x + local_id_y * local_size_x + local_id_x).

Inclusive Scan

In an inclusive scan, the result returned to a work-item includes its own input value:

  • work_group_scan_inclusive_add(T x)
  • work_group_scan_inclusive_min(T x)
  • work_group_scan_inclusive_max(T x)

Exclusive Scan

In an exclusive scan, the result returned to a work-item excludes its own input value and includes only values from preceding work-items. The identity value (e.g., 0 for addition, type infinity/min for min/max) is returned to the first work-item:

  • work_group_scan_exclusive_add(T x)
  • work_group_scan_exclusive_min(T x)
  • work_group_scan_exclusive_max(T x)

Synchronization Primitives

Collective algorithms depend on strict synchronization among group participants:

  • work_group_barrier(cl_mem_fence_flags flags, memory_scope scope): Synchronizes all work-items in the work-group and enforces memory ordering defined by flags (such as CLK_LOCAL_MEM_FENCE or CLK_GLOBAL_MEM_FENCE) across the designated memory scope.

Asynchronous Work-Group Memory Copies

These functions enable collective, high-throughput memory transfers between __global and __local memory:

  • async_work_group_copy(local/global T *dst, const global/local T *src, size_t num_elements, event_t event): Cooperatively copies data between global and local address spaces.
  • async_work_group_strided_copy(local/global T *dst, const global/local T *src, size_t num_elements, size_t stride, event_t event): Cooperatively copies data with a designated non-contiguous memory stride.
  • wait_group_events(int num_events, event_t *event_list): Blocks all work-items in the work-group until the specified asynchronous copy operations have completed.
