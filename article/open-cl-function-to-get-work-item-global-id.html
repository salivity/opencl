OpenCL Function to Get Work-Item Global ID

In OpenCL, parallel execution relies on tracking individual execution units across an N-dimensional grid, known as work-items. This guide details the specific built-in OpenCL function used to retrieve a work-item's unique global identifier, explains how its dimension parameters work, and provides standard implementation examples within a compute kernel.

The Built-in Function: get_global_id()

The built-in function that retrieves the global unique ID of an execution work-item in OpenCL is get_global_id().

Every work-item executing a kernel is assigned a unique global ID within the entire NDRange (N-Dimensional Range) dispatch. This function allows the kernel to determine which portion of the dataset it is responsible for processing.

Function Syntax and Parameters

The function signature is defined as follows:

size_t get_global_id(uint dimindx)
  • dimindx: An unsigned integer representing the dimension index for which you want to retrieve the ID.
    • 0 queries the first dimension (X-axis).
    • 1 queries the second dimension (Y-axis).
    • 2 queries the third dimension (Z-axis).
  • Return Value: Returns a value of type size_t representing the unique coordinate of the calling work-item within the specified dimension. If dimindx is greater than or equal to the total number of dimensions defined in the NDRange, the function returns 0.

Practical Usage in a Kernel

In a standard 1D data-parallel array operation, get_global_id(0) is used to map a single work-item directly to an array element:

__kernel void vector_add(__global const float *a,
                         __global const float *b,
                         __global float *result) 
{
    // Retrieve the unique global index for the 1D dimension
    size_t id = get_global_id(0);

    // Perform computation on the unique index
    result[id] = a[id] + b[id];
}

For two-dimensional tasks, such as matrix operations or image processing, get_global_id is called for both the X and Y coordinates:

__kernel void process_image(__global float *output, int width) 
{
    size_t x = get_global_id(0); // Column index
    size_t y = get_global_id(1); // Row index

    size_t index = y * width + x;
    output[index] = output[index] * 2.0f;
}

Related Work-Item Functions

While get_global_id() identifies a work-item across the entire execution space, it is commonly used alongside these complementary built-in functions:

  • get_global_size(uint dimindx): Returns the total number of global work-items in the specified dimension.
  • get_local_id(uint dimindx): Returns the unique ID of the work-item within its specific work-group.
  • get_group_id(uint dimindx): Returns the ID of the work-group that the work-item belongs to.
