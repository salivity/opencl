OpenCL Preprocessor Macros for Standard Versions

When developing cross-platform compute kernels, handling differences between OpenCL specifications requires reliable feature and runtime detection. OpenCL kernels feature built-in, compile-time preprocessor macros automatically set by the device compiler to reflect supported and targeted standard versions. These predefined macros allow developers to conditionally compile device code based on the OpenCL runtime environment and the specific OpenCL C shading language specification in use.

Primary Version Macros

The OpenCL C compiler automatically populates two primary macros to describe version details:

  • __OPENCL_VERSION__
    Present since OpenCL 1.0, this macro indicates the OpenCL version supported by the device. It evaluates to an integer corresponding to the major and minor version numbers. For example, OpenCL 1.0 evaluates to 100, OpenCL 1.1 to 110, OpenCL 1.2 to 120, OpenCL 2.0 to 200, and OpenCL 3.0 to 300.

  • __OPENCL_C_VERSION__
    Introduced in OpenCL 1.2, this macro identifies the version of the OpenCL C language specification used to compile the kernel. While __OPENCL_VERSION__ reflects device support, __OPENCL_C_VERSION__ reflects the dialect used by the compiler (which can be overridden at runtime via compilation flags such as -cl-std=CL1.2). It evaluates to an integer formatted similarly to __OPENCL_VERSION__ (e.g., 120 for OpenCL C 1.2, 200 for OpenCL C 2.0, or 300 for OpenCL C 3.0).

Version Constants for Conditional Checks

To make version comparisons readable and consistent, the OpenCL environment provides standard version comparison macros:

  • CL_VERSION_1_0: Evaluates to integer 100.
  • CL_VERSION_1_1: Evaluates to integer 110.
  • CL_VERSION_1_2: Evaluates to integer 120.
  • CL_VERSION_2_0: Evaluates to integer 200.
  • CL_VERSION_3_0: Evaluates to integer 300.

These constants allow developers to write standard #if directives directly inside kernel source files:

#if defined(__OPENCL_C_VERSION__) && (__OPENCL_C_VERSION__ >= CL_VERSION_2_0)
    // Code utilizing features introduced in OpenCL C 2.0 or later
#else
    // Fallback code for legacy OpenCL C specifications
#endif

C++ for OpenCL Macro

When targeting environments that use the C++ for OpenCL language extension, the compiler defines:

  • __OPENCL_CPP_VERSION__
    Defined when C++ for OpenCL is enabled, reflecting the version of the C++ OpenCL dialect (e.g., 100 for C++ for OpenCL version 1.0, corresponding to C++17 compatibility). In this mode, __OPENCL_C_VERSION__ is typically undefined unless explicit compatibility behavior is requested.
