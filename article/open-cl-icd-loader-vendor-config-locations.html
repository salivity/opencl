OpenCL ICD Loader Vendor Config Locations

The OpenCL Installable Client Driver (ICD) Loader acts as a central dispatcher that allows multiple OpenCL implementations (such as those from NVIDIA, Intel, and AMD) to coexist on a single system. To discover available platform drivers, the ICD loader checks specific vendor configuration locations defined by the operating system. On Linux, these configurations are managed through plaintext .icd files stored in system and user directories, whereas on Windows, the configurations are stored as registry entries rather than physical files.

Linux Vendor Configuration Locations

On Linux, the OpenCL ICD loader scans directories for files ending with the .icd extension. Each .icd file contains a single line of text specifying the absolute path or library name of the vendor's OpenCL implementation shared library (such as libcuda.so or libintelopencl.so).

The loader searches the following locations, typically in this order:

  1. User-specific Directory:
    ~/.local/share/OpenCL/vendors (or $XDG_DATA_HOME/OpenCL/vendors)
    Used for user-level installations without root privileges.

  2. System Distribution Directory:
    /usr/share/OpenCL/vendors/
    Commonly populated by Linux distribution package managers.

  3. System Administrative Directory:
    /etc/OpenCL/vendors/
    The primary standard path where system-wide vendor driver files are placed.

  4. Local Administrative Directory:
    /usr/local/etc/OpenCL/vendors/ or /opt/...
    Used for locally compiled or non-packaged vendor drivers.

Windows Vendor Configuration Locations

Unlike Linux, Windows does not store vendor configurations as standalone text files on the disk. Instead, the ICD loader queries the Windows Registry.

Vendors register their ICD DLLs by creating a REG_DWORD value under the following registry keys:

  • 64-bit Systems (Native 64-bit drivers):
    HKEY_LOCAL_MACHINE\SOFTWARE\Khronos\OpenCL\Vendors

  • 32-bit Drivers on 64-bit Systems (WOW64):
    HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Khronos\OpenCL\Vendors

  • 32-bit Systems:
    HKEY_LOCAL_MACHINE\SOFTWARE\Khronos\OpenCL\Vendors

Within these keys, the Value Name is the full path or filename of the vendor's driver library (for example, C:\Windows\System32\nvopencl.dll), and the Value Data is set to 0 (a REG_DWORD value indicating the driver is active and ready to be loaded).
