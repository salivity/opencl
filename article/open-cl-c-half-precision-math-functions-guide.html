OpenCL C Half-Precision Math Functions Guide

OpenCL C supports half-precision floating-point arithmetic primarily through the cl_khr_fp16 extension, allowing developers to optimize memory bandwidth and computational throughput on compatible hardware. When this extension is supported and enabled, the OpenCL C standard library extends virtually all of its built-in mathematical functions to operate directly on the 16-bit scalar half data type and its corresponding vector types (half2, half3, half4, half8, and half16).

Enabling Half-Precision Support

To access standard mathematical functions operating natively on 16-bit floats, the extension must be enabled in the kernel source code:

#pragma OPENCL EXTENSION cl_khr_fp16 : enable

Note: These native operations are distinct from the legacy half_ prefixed functions (such as half_sin or half_sqrt), which take 32-bit float arguments and compute results with 10-bit half-precision accuracy.

Supported Mathematical Functions

When cl_khr_fp16 is active, the following OpenCL C math functions accept half and halfn types as input and return half or halfn outputs:

Trigonometric and Hyperbolic Functions

  • Basic Trigonometry: cos, sin, tan, acos, asin, atan, atan2
  • Normalized Trigonometry (Pi Multiples): cospi, sinpi, tanpi, acospi, asinpi, atanpi, atan2pi
  • Hyperbolic: cosh, sinh, tanh, acosh, asinh, atanh
  • Sincos Utility: sincos (computes both sine and cosine simultaneously)

Exponential and Logarithmic Functions

  • Exponentials: exp, exp2, exp10, expm1 (\(e^x - 1\))
  • Logarithms: log, log2, log10, log1p (\(\ln(1 + x)\)), logb, ilogb

Power and Root Functions

  • Exponents & Roots: pow, pown (integer exponent), powr (\(x^y\) where \(x \ge 0\)), rootn (\(n\)-th root)
  • Square and Cube Roots: sqrt, rsqrt (\(1 / \sqrt{x}\)), cbrt
  • Distance: hypot (\(\sqrt{x^2 + y^2}\))

Rounding, Clamping, and Remainder Functions

  • Rounding: ceil, floor, trunc, round, rint, nearbyint
  • Remainder & Division: fmod, remainder, remquo, fdim

Floating-Point Manipulation

  • Decomposition & Scaling: frexp, ldexp, modf, fract
  • Sign and Step Operations: copysign, fabs, nextafter, nan

Fused and Multiply-Add Functions

  • Arithmetic Combinations: fma (fused multiply-add with single rounding), mad (multiply-add with implementation-defined precision)

Common and Relational Functions

In addition to <math.h> equivalents, OpenCL C's built-in common and relational libraries also support the half type. This includes:

  • clamp, max, min, mix, degrees, radians, sign, smoothstep, and step
  • Relational comparisons such as isequal, isgreater, isnan, and isinf
