How to Check OpenCL Device Extension Support

This article explains how an OpenCL host program can determine whether a specific vendor extension is supported on an active target device. By leveraging the OpenCL runtime API to query device capabilities, developers can inspect the available extensions at runtime and safely enable hardware-specific optimizations or fallback paths.

To determine if an active OpenCL device supports a specific vendor extension, the host application must call clGetDeviceInfo using the CL_DEVICE_EXTENSIONS flag. This function returns a space-separated string containing the names of all extensions supported by the designated device.

Querying the Extension String

Retrieving the extension list is typically performed in two steps: first querying the required buffer size, allocating the memory, and then fetching the actual string.

#include <CL/cl.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int is_extension_supported(cl_device_id device, const char *extension_name) {
    size_t ext_size = 0;
    
    // Step 1: Query the size of the extension string
    cl_int err = clGetDeviceInfo(device, CL_DEVICE_EXTENSIONS, 0, NULL, &ext_size);
    if (err != CL_SUCCESS || ext_size == 0) {
        return 0;
    }

    // Step 2: Allocate memory and retrieve the extension string
    char *extensions = (char *)malloc(ext_size);
    if (!extensions) {
        return 0;
    }

    err = clGetDeviceInfo(device, CL_DEVICE_EXTENSIONS, ext_size, extensions, NULL);
    if (err != CL_SUCCESS) {
        free(extensions);
        return 0;
    }

    // Step 3: Safely search for the extension
    int supported = 0;
    const char *start = extensions;
    size_t ext_len = strlen(extension_name);

    while (1) {
        const char *match = strstr(start, extension_name);
        if (!match) {
            break;
        }

        // Verify boundary conditions to avoid matching substrings
        char prev = (match == extensions) ? ' ' : *(match - 1);
        char next = *(match + ext_len);

        if ((prev == ' ' || prev == '\0') && (next == ' ' || next == '\0')) {
            supported = 1;
            break;
        }

        start = match + ext_len;
    }

    free(extensions);
    return supported;
}

Parsing Considerations

A naive substring search using functions like strstr without boundary verification can result in false positives. For instance, querying for cl_khr_fp16 could inadvertently match a longer extension name containing that substring. Ensure that the matched string is bounded on both sides by spaces or string terminators.

OpenCL 3.0 and Newer Approaches

For applications targeting OpenCL 3.0 or later, devices can also be queried using CL_DEVICE_EXTENSIONS_WITH_VERSION. This query returns an array of cl_name_version structures, containing both the extension name and a packed version integer:

size_t num_bytes = 0;
clGetDeviceInfo(device, CL_DEVICE_EXTENSIONS_WITH_VERSION, 0, NULL, &num_bytes);

size_t num_exts = num_bytes / sizeof(cl_name_version);
cl_name_version *ext_versions = (cl_name_version *)malloc(num_bytes);
clGetDeviceInfo(device, CL_DEVICE_EXTENSIONS_WITH_VERSION, num_bytes, ext_versions, NULL);

for (size_t i = 0; i < num_exts; i++) {
    if (strcmp(ext_versions[i].name, "cl_arm_printf") == 0) {
        // Extension found, with version: ext_versions[i].version
    }
}
free(ext_versions);

Using CL_DEVICE_EXTENSIONS_WITH_VERSION eliminates string tokenization overhead and allows the host to verify the specific specification version of the vendor extension before invocation.
